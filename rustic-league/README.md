# Rustic League

Rusty-car soccer in the browser (Babylon.js, custom physics, procedural textures), with bots, 1v1–4v4 matches, LAN parties and phone/tablet controls.

- **Play:** `dist/rustic-league.html` (single player, open it in a browser) or deploy `dist/rustic-league-vercel.zip` to Vercel for LAN parties (see `vercel/README.md`).
- **Continue development in a new chat:** start with `HANDOFF.md`, then `ARCHITECTURE.md`, `BOTS.md` and `MULTIPLAYER.md`.
- **Build:** `python3 build.py prod` writes `dist/rustic-league.html`; `python3 build.py vercel` writes `vercel/index.html`.
